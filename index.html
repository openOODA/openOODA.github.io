Tokens

No ambient authority. An effect needs a token argument such as &FsReadCap or &HttpCap. No token, no effect. Missing or forged tokens fail closed. See capabilities.

Writes and HMAC. You cannot mint a token from bytes. write_file needs &FsWriteCap and OODA_FS_WRITEDIR. HMAC attenuation derives a narrower child seal. See start.

SECRET fields. A field marked SECRET must not go to println or process_exec. ooda check refuses it. See language.

Landlock and quotas. Under &SysCap the runtime can apply a Linux Landlock jail and POSIX setrlimit. Empty allowlists and zero quotas fail closed. See how it works.

Libraries

Wire packs. HTTP/2 writes a 9-byte header and a 24-bit length. WebSocket applies a 4-byte XOR mask. DNS builds QNAME labels. MQTT encodes remaining length. PostgreSQL v3 packs StartupMessage and Query. MySQL packs handshake v10 and COM_QUERY. RESP recovers plus, minus, colon, dollar, and star. Encode then decode recovers the fields. See home.

Crypto. ChaCha20-Poly1305 open fails closed on a bad tag. Ed25519 multiplies points. Shamir needs k shares. TOTP builds 6-digit and 8-digit codes on 30-second steps.

Matrices, geometry, and files. BLAS, LU, and QR run on small Float matrices. vec2 and vec3 compute dot, cross, and reflection. look_at and perspective are not identity. An R-tree answers overlap and nearest-neighbor. A convex hull has positive area. Inspectors read ELF64, Mach-O, and WASM headers. Huffman and LZ77 restore source bytes.

Collections and DSP. A B-tree splits full nodes. A Bloom filter never misses an inserted key. LRU evicts the least-recent key. A skip list stays ordered. Gaussian, Sobel, and Laplacian change pixels. A biquad low-pass and high-pass differ on a DC step. Linear and sinc resample change length with the sample-rate ratio.

Pins

Package identity. The lock line carries a sha256 of the bytes. A different byte string is a different package. ooda launch --exec checks sha, caps, and yank before it runs. See packages.

Foreign ELF. A foreign ELF does not receive openOODA tokens. Undeclared caps are refused. See capabilities.

Measured isolate. The isolate hash covers payload, token, and domain. It is a hash. It is not a hardware enclave. See how it works.

Locks

Lock line. Each lock is name@version#sha256#CapName. The cap name is the token that package may use. See capabilities.

Store and 402. ooda add hello uses the stock store. A package may quote HTTP 402 / x402. See pay.

More: packages, pins, active defense.

Agents

Small tools. Use outline, reflect, fix, and patch on one file or one function. Do not dump a full emit. See language.

Machine diagnostics. ooda lsp completes on &. check --json-errors prints structured errors. See commands.

Files
  • ~/.local/bin/ooda — the command driver
  • ~/.local/bin/oodac — the single-pass compiler
  • ~/.local/share/ooda/std/ — verified standard library
  • ~/.local/share/ooda/runtime/ — minimal C runtime for ooda run
  • ~/.local/share/ooda/share/fixtures/hello.oo — canonical entry fixture
  • ~/.config/ooda/env — hermetic PATH and OODA_* variables

Product path. ooda check typechecks. ooda run emits C, compiles with host gcc, and execs. ooda test runs verify. See commands.

Defense

Defense on by default. Everyday emit-c keeps binary defense on. Use --plain or --debug to opt out. See active defense.

What the morpher does. It can flatten control flow, permute blocks, and rewrite gadget-like byte runs. String encrypt and decoy symbols live on that page. See how it works.

Tokens still bind. A morphed binary does not mint &FsReadCap or &ProcessCap. Landlock still needs &SysCap. Read capabilities.
