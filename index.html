Capability security (real)

Default-deny sealed builtins. Explicit &NetCap / &FsCap / &SysCap / &EnvCap. Runtime gate in the interpreter.

🧪

Contracts & verify (real)

requires / ensures at runtime. Co-located verify via ooda test.

🔢

Integer LLVM + partial WAT

ooda build emits validated Int/Bool IR. --target wasm emits subset .wat or fails non-zero. String programs use ooda run.

🔐

Crypto & JSON (real)

sha2 / hmac / serde_json internals with real digests.

🤖

AI-oriented tools (partial)

--json-errors with line:col, outline, reflect, context, patch.

⚠️

Not implemented (honest)

No full WASM/WASI product, no PyTorch bridge, no LSP, no package downloads, no migrate/replay. Those fail closed.
