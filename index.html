Correct paths

Capabilities

Installer itself requires &NetCap &FsCap &SysCap &EnvCap — default-deny even for setup.

⚠️

Gaps

Bootstrap shell is Chapter 0 only. Full SPEC self-host not claimed. Std is a slot you clone into OODA_STD.

After install:

. ~/.config/ooda/env
ooda --version
git clone https://github.com/openOODA/ooda.git && cd ooda
ooda run examples/while_count.oo
# optional std:
git clone https://github.com/openOODA/std.git "$OODA_STD"
