Build fast. Stay secure. Save tokens.

A systems language. You write .oo. A function that talks to the world holds a token. If the token is not there, the call does not run.

Why

Effects

In Rust, Go, Zig, and C, a function can use files or the network if the process can. In openOODA the function must hold a token, for example &FsReadCap. No token, no effect.

Agents

Other languages expect a person to read full source files. openOODA gives a short loop: outline, reflect, fix, and patch one function. The agent does not send the full project to the model.

Secrets

If you print a key, the key leaves the program. Mark a field SECRET. Check stops a print of that field.

Packages

A lock line is name@version#sha256#CapName. The line names the hash and the permitted effect. Extra rights are refused. See the verifiable web of code.

Safety

tokens

A file, process, or network call takes a capability as an argument. If the token is missing, false, or zero, the call stops. Use the smallest token that does the job. Do not take &SysCap when &FsReadCap is enough.

writes

write_file needs &FsWriteCap and OODA_FS_WRITEDIR. If that environment value is not set, the write is denied. Absolute paths and symbolic links are refused.

secrets

Mark a field SECRET. println of that field fails check. process_exec is a secret sink. A sink is a call that must not receive a secret.

jail

On Linux, &SysCap can apply a Landlock jail and POSIX setrlimit. An empty path list fails closed. A zero quota fails closed.

Packages

A lock line is name@version#sha256#CapName. The line names the bytes and the permitted effect. Extra capabilities are refused. A path that leaves the package tree is refused.

ooda add hello uses the stock store. ooda search walks every store you added. Extra stores: ooda registry add https://host. A yanked name is refused. ooda launch --exec runs the gated payload after the hash, the caps, and the yank check. A foreign ELF file does not receive Ooda tokens from a lock line.

Measured isolate hashes the payload, the token, and the domain. The file on disk stays the same so a rebuild can match. See reproducible builds and the verifiable web of code.
