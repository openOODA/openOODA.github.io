🔒

Capability security (real)

Default-deny sealed builtins (fetch, .write_file, …). Requires explicit &NetCap / &FsCap / &SysCap / &EnvCap. Runtime gate in the interpreter.

🧪

Contracts & verify (real)

requires / ensures evaluated at runtime. Co-located verify blocks via ooda test. Fuzzer samples multi-param boundaries.

🔢

Integer LLVM IR (real, subset)

ooda build emits type-consistent IR for Int/Bool straight-line programs and validates it. String programs → use ooda run.

🔐

Crypto & JSON (real)

sha2 / hmac / serde_json backed internals. Empty-string SHA-256 matches the standard digest.

🤖

AI-oriented tools (partial)

--json-errors with real line:col, ooda outline, ooda reflect, ooda context (outline-based), ooda patch (real body replace).

⚠️

Not implemented (honest)

No WASM bytecode, no PyTorch bridge, no LSP server, no package downloads, no migrate/replay. Those commands exit non-zero instead of faking success.

Quick start after install

ooda --version
ooda run examples/hello.oo
ooda test examples/math_contract.oo
ooda build examples/int_main.oo --emit-llvm
ooda run --json-errors broken.oo   # diagnostics include line + column
