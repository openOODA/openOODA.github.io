The capability-secure & self-testing systems language

Built around the OODA Loop (Observe · Orient · Decide · Act): sealed capability security, design-by-contract, refinement types, and dual JIT / LLVM / WASM execution.

$ curl -fsSL https://openOODA.github.io/install | sh

Pins v0.23.0-alpha (override with OODA_VERSION). Layout: ~/.local/bin/ooda, ~/.local/share/ooda, ~/.config/ooda/env.

👁️ OBSERVE
Static AST spans & AI JSON error diagnostics
🧭 ORIENT
Sealed capability gates (&NetCap, &FsCap) & Int[min..max]
⚖️ DECIDE
Contracts (requires, ensures result, verify blocks)
⚡ ACT
JIT + LLVM + WASM & atomic auto-fix (ooda patch)
🔒

Sealed Capabilities

Default-deny security model. Sealed builtins check capability tokens (&NetCap, &FsCap, &SysCap, &EnvCap) statically and at runtime.

📜

Design by Contract

Preconditions (requires), postconditions (ensures result), static refinement bounds (Int[1..65535]), and co-located verify blocks.

🤖

AI Diagnostic Native

Machine-readable JSON diagnostics (--json-errors) with AST source spans and atomic in-memory surgical patch repairs (ooda patch).
